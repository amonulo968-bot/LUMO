✨ LUMO — пространство для твоих идей

LUMO — универсальное приложение для заметок, задач и организации мыслей. Это единое цифровое пространство, в котором можно сохранять идеи, планировать дела, создавать списки и визуально структурировать информацию.

Приложение объединяет привычные инструменты для повседневной организации в одном удобном и современном интерфейсе. Никаких лишних сложностей — только необходимые функции, гибкая настройка и быстрый доступ к важной информации.

---

🚀 Основные возможности

📝 Заметки

- Создание, редактирование и удаление записей.
- Поиск и сортировка заметок.
- Удобная организация личной информации.
- Работа с содержимым через отдельный редактор.

☑️ Задачи и чек-листы

- Создание списков дел и отдельных задач.
- Добавление и редактирование пунктов.
- Отметка выполненных задач.
- Визуальное отслеживание прогресса выполнения.

🧩 Интерактивные доски

- Свободное размещение текстовых блоков.
- Добавление изображений.
- Создание связей между элементами с помощью стрелок.
- Визуальная организация идей, планов и информации.

🎨 Персонализация

- Светлая и тёмная темы оформления.
- Настройка цветового акцента.
- Изменение размера текста.
- Управление анимациями и вибрацией.
- Поддержка русского и английского языков.

📦 Управление данными

- Импорт и экспорт информации.
- Создание резервных копий.
- Корзина для удалённых элементов.
- Возможность восстановления записей.

---

🛠️ Технологии

Проект построен на основе веб-технологий:

- HTML5 — структура приложения.
- CSS3 — оформление, адаптивность и визуальные эффекты.
- JavaScript — логика, интерактивность и управление данными.
- IndexedDB — основное хранилище данных.
- LocalStorage — дополнительный механизм хранения.

---

🎯 Концепция проекта

Главная идея LUMO — объединить разные способы организации информации в одном приложении.

Заметки помогают сохранять мысли, списки — контролировать задачи, а интерактивные доски — связывать идеи и выстраивать их в единую систему.

LUMO создаётся с акцентом на удобство использования, визуальную простоту, гибкость и возможность дальнейшего развития.
